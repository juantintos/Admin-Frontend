# 💻 Frontend - Sistema de Gestión

> Aplicación web desarrollada en Angular 19 para consumo de API REST del backend Laravel.  
> Incluye módulos de usuarios, perfiles, dashboard y auditoría de cambios.

---

# 🚀 Tecnologías

- Angular 19
- TypeScript 5
- PrimeNG 19
- PrimeIcons
- RxJS
- SCSS

---

# 📦 Instalación

```bash
git clone <URL_FRONTEND>
cd frontend
npm install
```

▶️ Ejecución del proyecto
```bash
ng serve
```

Aplicación disponible en:
```bash
http://127.0.0.1:8000/api
```
